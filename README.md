# Apuração 2026 ao vivo

Painel com os dados abertos oficiais do TSE (resultados.tse.jus.br), lidos direto do navegador a cada 30 s.

- `index.html`: painel do tablet (Presidente, Governador, Senador)
- `completo.html`: todos os cargos, incluindo deputados
- `version.json`: ao mudar, os painéis abertos recarregam sozinhos com a versão nova
